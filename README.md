# 🚀 LPU AutoLogin+ (Chrome Extension)
Automatically logs you into **LPU 24Online Internet Portal** every time you connect to Wi-Fi.  
No more typing ID, password, or ticking Terms & Conditions!

---

## ✅ Features
✔ Auto-fills Username  
✔ Auto-fills Password  
✔ Auto-ticks "Agree with Terms & Conditions"  
✔ Auto-enables the Login button  
✔ Auto-clicks Login  
✔ Works seamlessly on:  
`https://internet.lpu.in/24online/webpages/client.jsp`

## 🛠 Installation
1. Download the ZIP  
2. Extract it  
3. Open Chrome → `chrome://extensions`  
4. Enable **Developer Mode**  
5. Click **Load Unpacked**  
6. Select the `extension/` folder  

Done! Your LPU Wi-Fi will auto-login every time 🎉

---

## 🔧 How it Works (Simplified)
The extension:
- Detects the login page  
- Inserts your saved credentials  
- Triggers all required validation events  
- Calls LPU’s internal function: `appendUserName()`  
- Activates the Login button  
- Auto-clicks Login
